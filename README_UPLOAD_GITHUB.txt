PANDUAN UPLOAD KE GITHUB PAGES (SC-SANSCHAT PWA)
================================================
1. Ekstrak file ZIP ini.
2. Upload seluruh isi file di dalamnya ke repository GitHub Anda (timpa file lama):
   - index.html
   - login.html
   - utama.html
   - manifest.json
   - service-worker.js
3. Semua konfigurasi API Google Apps Script, sinkronisasi Google Sheet, Role warga,
   dan penyimpanan sesi tetap 100% sama tanpa perubahan logika backend.
4. Perubahan hanya pada tata letak UI & margin agar presisi seperti WhatsApp Android
   (layar penuh tanpa bingkai luar di HP, bubble chat, gambar, foto, video, dan input bar).
